# APT Reserve 2 - 아파트 방문예약 시스템

## 개요

`reserve-apt2.co.kr`(그누보드 기반 아파트 방문예약 사이트)의 기능을 자체 서버에서 독립 운영하기 위해 Next.js 풀스택으로 재구현한 예약 관리 시스템.

## 핵심 기능

### 관리자 (Admin)

| 기능 | 설명 | 상태 |
|------|------|------|
| 관리자 로그인 | ID/비밀번호 기반 인증, JWT 세션 쿠키 | 구현 완료 |
| 계정 관리 | 비밀번호 변경 (현재 비밀번호 확인 필수) | 구현 완료 |
| 행사 관리 | 방문 이벤트 생성/수정/삭제, 기간 설정 | 구현 완료 |
| 시간대 관리 | 날짜별 시간대 슬롯 생성, 정원 설정 | 구현 완료 |
| 예약 관리 | 예약 현황 조회, 상태 변경 (확정/취소) | 구현 완료 |
| 대시보드 | 통계 요약, 예약 현황 한눈에 보기 | 구현 완료 |

### 공개 (Public)

| 기능 | 설명 | 상태 |
|------|------|------|
| 예약 접수 | 달력 선택, 시간대 선택, 인원 입력 | 구현 완료 |
| 예약 확인 | 연락처로 예약 내역 조회 | 구현 완료 |
| 예약 취소 | 예약 ID 기반 취소 처리 | 구현 완료 |
| 이메일 알림 | 예약 완료/취소 시 이메일 발송 | 구현 완료 |

## 사용자 역할

| 역할 | 설명 |
|------|------|
| 관리자 (Admin) | 행사/시간대/예약 관리, 대시보드 접근 |
| 일반 사용자 | 예약 접수, 예약 확인/취소 |

## 데이터 모델

```
Admin ── (인증) ── 관리자 전용 API
Event ──< TimeSlot ──< Reservation
                  └── capacity (정원 관리)
```

- **Admin**: 관리자 계정 (username, passwordHash, isSuper)
- **Event**: 행사 (title, 기간, 활성 상태)
- **TimeSlot**: 시간대 슬롯 (date, label, capacity)
- **Reservation**: 예약 (이름, 동/호, 연락처, 인원, 상태)
